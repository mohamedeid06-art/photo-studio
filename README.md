# استوديو التأشيرات والجوازات الذكي (KSA Visa & Passport Batch Photo Studio)

تطبيق ويب عربي احترافي (`RTL`) لمعالجة صور التأشيرات وجوازات السفر بالجملة، مصمم ومُعاير خصيصاً لمطابقة اشتراطات **موقع وزارة الخارجية السعودية / منصة التأشيرات (إنجاز)**، ويعمل **100% داخل المتصفح (Client-Side)** بدون أي خادم خلفي لضمان أقصى درجات السرعة والخصوصية.

---

## ✨ المميزات الرئيسية

1. **إزالة الخلفية بالذكاء الاصطناعي عالي الدقة (`@imgly/background-removal`):**
   - يعمل بالكامل داخل المتصفح عبر تقنية `WebAssembly / ONNX` باستخدام النموذج عالي الدقة (`medium`) للحفاظ على تفاصيل الشعر والحجاب والشماغ/الغترة، مع استبدال الخلفية باللون الأبيض الناصع `#FFFFFF`.
2. **كشف الوجه والتوسيط التلقائي الذكي (`@mediapipe/tasks-vision` + Alpha Mask):**
   - يدمج بين صندوق كشف الوجه (`FaceDetector`) وأعلى نقطة فعلية في القناع المفرغ (`Alpha Mask`) لحماية أطراف الشماغ أو الحجاب من القص العلوي، مع توسيط الرأس أفقياً وضبط نسبة الرأس والكتفين تلقائياً.
3. **خوارزمية الضغط الثنائي الذكي (`Smart Binary-Search JPEG Compression`):**
   - تبحث تلقائياً عن أعلى جودة `JPEG` ممكنة بحيث يكون حجم الملف النهائي مضموناً بين **`15 KB` و `240 KB`** (أو الحد المخصص) لعدم رفض الصورة أبداً في موقع وزارة الخارجية.
4. **تحديث فوري للتعديلات بدون إعادة تشغيل الذكاء الاصطناعي:**
   - يتم الاحتفاظ بالصورة المفرغة الشفافة في الذاكرة بحيث أي تعديل في (الإضاءة / التباين / الحدة / تنعيم الحواف / المقاس) يُطبق في أجزاء من الثانية.
5. **تعديل يدوي متقدم (`react-easy-crop`) مع شبكة إرشادية:**
   - نافذة تعديل يدوي لكل صورة تحتوي على شبكة إرشادية بيومترية للرأس والكتفين، ومعاينة حية لحجم الملف النهائي بالكيلوبايت أثناء التحريك والتقريب.
6. **تصدير بالجملة (`JSZip` + `file-saver`):**
   - تحميل جميع الصور الجاهزة مباشرة في جذر ملف `.zip` واحد مع الاحتفاظ بالاسم الأصلي لكل ملف وإمكانية تعديل الاسم مباشرة من البطاقة.

## 🗂️ هيكلية المشروع المقسمة (Modular Architecture)

```text
src/
├── main.jsx                       # نقطة الدخول الرئيسية للتطبيق
├── App.jsx                        # المكون الأب وتنسيق لوحة التحكم
├── index.css                      # تنسيقات Tailwind CSS والمنزلقات العربية
├── constants/
│   └── presets.js                 # قوالب المقاسات المعتمدة (الخارجية السعودية، جواز 4×6، مخصص)
├── services/
│   ├── backgroundRemoval.js       # خدمة الذكاء الاصطناعي لتفريغ الخلفية بدقة فائقة
│   ├── faceDetection.js           # خدمة كشف الوجه ودمج القناع المفرغ لحماية الشماغ/الحجاب
│   ├── imageProcessor.js          # محرك الرسم على Canvas وتنعيم الحواف والضغط الثنائي الذكي
│   └── zipExporter.js             # خدمة التصدير المنفرد وتصدير ملف ZIP مع حفظ الأسماء الأصلية
├── hooks/
│   ├── usePhotoQueue.js           # إدارة طابور الصور، التوازي المتحكم به، وتحرير الذاكرة (RAM)
│   └── useTheme.js                # إدارة الوضع النهاري (الافتراضي) والوضع الليلي
└── components/
    ├── Header.jsx                 # الشريط العلوي وإحصائيات الطابور السريعة
    ├── SettingsPanel.jsx          # لوحة إعدادات المقاس، حجم الملف، وتحسين الإضاءة والحدة
    ├── DropzoneUploader.jsx       # منطقة السحب والإفلات لرفع الصور بالجملة
    ├── BulkActionBar.jsx          # شريط العمليات الجماعية ومؤشر التقدم وتحميل نموذج الـ AI
    ├── PhotoGrid.jsx              # شبكة العرض مع التصفية والبحث باسم الملف
    ├── PhotoCard.jsx              # بطاقة الصورة مع معاينة (قبل/بعد) وتعديل الاسم والتحميل
    └── ManualCropModal.jsx        # نافذة القص اليدوي مع الشبكة الإرشادية للرأس والكتفين
```
